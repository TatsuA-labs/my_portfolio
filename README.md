## About Site
### Frontend
Next.js(Typescript)
・SSRやSSGが可能であるため、SEOに有利である。
・Reactに比べて、初期実装までが楽である。

Css Modules + Scss
・Css Modulesは、CSSのスコープを持つことができるため、コンポーネントごとにCSSを管理することができる。
・Scssの変数等機能を使いたい。
・build時間が短い。

BCDデザイン
Atomicデザインをより簡略化したもの。
より直感的にわかりやすく、管理がしやすいため採用。
