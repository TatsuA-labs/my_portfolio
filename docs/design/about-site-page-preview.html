このサイトについて

このポートフォリオサイトの技術選定と開発手法について紹介します。

サイトの目的

ポートフォリオサイトとしての役割

自分に興味を持っていただいた皆様に対して、アピールする場としての役割と、自分自身の過去を見直す役割を期待して作成しています。

技術的な興味を満たす場としての役割

ポートフォリオの改修や、遊び場の追加を通して、自身の技術的なインプットとアウトプットとしても役割を期待しています。また、極力ライブラリを使わずに実装することを目指しています。

AI開発について

このサイトはAI開発ツール（Cursor）を活用して開発しています。AI開発により、要件の整理から設計、デザイン、実装、レビュー、PR作成まで、一貫したワークフローで高品質な開発を実現しています。

1

要件の具体化

依頼内容を整理し、スコープ・優先度・制約を明確にする。

  • 成果物: 要件の整理と確認事項のリスト
2

詳細設計

要件に基づき、データ構造・API・コンポーネント構成・ルーティングなどを設計する。

  • データ構造の定義
  • API 設計
  • コンポーネント構成図（Atomic デザインの階層を明記）
  • ルーティング設計
3

デザイン

詳細設計に基づき、視覚的なデザインを生成する。

  • 構造化デザイン仕様（Markdown表形式）
  • 簡易HTML/CSSコード（プレビュー用）
  • Atomic デザイン階層の明記
4

開発

承認されたデザインと詳細設計に従って実装する。

  • Atomic デザインの階層構造を厳守
  • 各コンポーネントを正しいディレクトリに配置
5

レビュー・セキュリティチェック

実装の品質確認に加え、セキュリティチェックを行う。

  • コードレビュー
  • セキュリティチェック
  • Shannon（生成AIによる自動脆弱性診断ツール）の実行
6

PR 作成

変更をブランチにまとめ、PR を作成する。

  • Pull Request の作成
