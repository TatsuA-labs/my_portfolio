# サイトについてページ デザイン仕様書（ゼロベース）

現状の実装に引きずられず、「最適なポートフォリオサイトの技術紹介ページ」を目的から定義し直したデザインです。承認後に実装に進みます。

---

## 1. デザインの目的と原則

### 1.1 目的
- **誰向けか**: 採用担当・クライアント・協業したい開発者・技術に興味のある人
- **何を伝えるか**: このサイトがどのような技術・ライブラリ・方法で作られているか、AI開発の活用方法
- **ゴール**: 技術選定の理由とAI開発の効果を明確に伝え、技術力と開発手法への理解を深めてもらう

### 1.2 原則（0ベースで採用）
| 原則 | 具体的な方針 |
|------|----------------|
| **情報の優先順位** | ページタイトル → サイトの目的 → 技術スタック → AI開発の紹介 |
| **可読性** | 行の長さを抑える（本文ブロック max-width 約 65ch）、行間 1.6〜1.75、段落間に余白 |
| **余白** | スペーシングをスケールで統一し、詰めすぎない。セクション間に「息をつく」余白 |
| **色は絞る** | 背景・文字・補足＋**1つのアクセント**（リンク・強調）。既存トークンを使用 |
| **一貫性** | 見出し・本文・キャプションのフォントサイズと太さをスケールで統一 |
| **レスポンシブ** | モバイルファースト。タッチしやすいタップ領域、読みやすいフォントサイズ |
| **アクセシビリティ** | コントラスト比 WCAG AA、フォーカス表示、セマンティックHTML・ARIA |

## 2. デザインシステム（既存トークンを活用）

### 2.1 カラー
既存のデザイントークンを使用：
- `--background`: ページ背景
- `--foreground`: 本文・見出し
- `--muted`: 補足テキスト
- `--accent`: リンク・強調
- `--section-bg`: セクション背景（交互の差し色）

### 2.2 タイポグラフィスケール
| 役割 | サイズ | 行間 | 太さ | 用途 |
|------|--------|------|------|------|
| H1 | 1.75rem〜2rem（28〜32px） | 1.25 | 700 | ページタイトル |
| H2 | 1.5rem（24px） | 1.3 | 700 | セクション見出し |
| H3 | 1.25rem（20px） | 1.4 | 600 | サブセクション見出し |
| リード | 1.125rem（18px） | 1.6 | 400 | ページタイトル直下の説明 |
| 本文 | 1rem（16px） | 1.7 | 400 | 通常段落 |
| キャプション・補足 | 0.875rem（14px） | 1.5 | 400 | 日付・ラベル |

### 2.3 スペーシングスケール（8pxベース）
既存のトークンを使用：
- `--xs`: 8px
- `--sm`: 16px
- `--md`: 24px
- `--lg`: 32px
- `--xl`: 48px
- `--2xl`: 64px
- `--3xl`: 96px

### 2.4 ブレークポイント
| 名前 | 幅 | 方針 |
|------|-----|------|
| モバイル | 〜767px | 1カラム、タップ領域 44px 以上 |
| タブレット | 768px〜1023px | 1〜2カラム、余白は中程度 |
| デスクトップ | 1024px〜 | max-width 1100px でコンテンツ幅を制限、余白を大きく |

## 3. ページ構造とセクション順（0ベース）

1. **ページタイトル** — H1「このサイトについて」＋リード文
2. **サイトの目的** — ポートフォリオサイトとしての役割、技術的な興味を満たす場としての役割
3. **技術スタック** — フロントエンド、バックエンド、DB、インフラ、その他（Lint/Format、状態管理、UIコンポーネント、アイコン、セキュリティ）
4. **AI開発について** — 概要とワークフローの紹介（新規）

## 4. コンポーネント仕様（0ベース）

### 4.1 ページタイトル

| 要素 | 仕様 | 意図 |
|------|------|------|
| コンテナ | 全幅、padding 上下 2xl、中央寄せ | 余白で「入り口」を明確に |
| H1 | 「このサイトについて」。H1のフォントサイズ・行間 | ページの目的を明確に |
| リード文 | H1の下、1〜2行。リードのフォントサイズ・行間、色は `--muted` | 補足説明は短く |
| HR | H1の下、max-width 1100px、高さ 1px、色は `--muted`、opacity 0.5 | セクションの区切り |

### 4.2 サイトの目的セクション（AboutSiteSection）

| 要素 | 仕様 | 意図 |
|------|------|------|
| セクション | padding 上下 2xl、コンテナ max-width 1100px、中央寄せ | 他のページと統一 |
| H2 | 「ポートフォリオサイトとしての役割」「技術的な興味を満たす場としての役割」 | セクション見出し |
| 本文 | H2の下、本文サイズ、max-width 65ch、行間 1.7 | 可読性 |
| カード | 各目的ごとにカード形式。背景 `--background`、ボーダー 1px solid `--muted`（opacity 0.3）、角丸 8px、padding md、margin-bottom md | 視覚的な区切り |

### 4.3 技術スタックセクション（TechStackSection）

| 要素 | 仕様 | 意図 |
|------|------|------|
| セクション | padding 上下 2xl、コンテナ max-width 1100px、中央寄せ、背景 `--section-bg`（交互の差し色） | セクションの区別 |
| H2 | 「本サイトを構成する技術」。下に md 以上の余白 | セクション見出し |
| カテゴリカード | 各カテゴリ（フロントエンド、バックエンド、DB、インフラ、その他）ごとにカード。背景 `--background`、ボーダー 1px solid `--muted`（opacity 0.3）、角丸 8px、padding md、margin-bottom md | 視覚的な区切り |
| H3 | カテゴリ名（例: 「フロントエンド」）。H3のフォントサイズ・行間 | カテゴリ見出し |
| 技術項目 | H3の下、リスト形式。各項目に「名前」「説明（任意）」「理由（任意、リスト形式）」を表示 | 情報の階層構造 |
| 技術名 | 太字（font-weight 600）、本文サイズ | 強調 |
| 説明 | 技術名の下、キャプションサイズ、色 `--muted` | 補足情報 |
| 理由リスト | 説明の下、ul/li形式、キャプションサイズ、行間 1.6、padding-left md | 理由の明確化 |

### 4.4 AI開発セクション（AIDevelopmentSection）

| 要素 | 仕様 | 意図 |
|------|------|------|

## 5. 情報の見やすさ・UX

| 観点 | 対応 |
|------|------|
| 階層 | H1 は1回（ページタイトル）、各セクション H2、カテゴリ・ステップ H3。番号飛ばしなし |
| コントラスト | 本文・背景は AA 以上。補足は muted で十分な比 |
| 行長 | 本文ブロック max-width: 65ch または 720px |
| セクション間 | セクション間に適切な余白（xl から 2xl）を確保 |
| カード | カード形式で情報を整理し、視覚的な区切りを明確に |

## 6. レスポンシブ・アクセシビリティ・SEO

| 項目 | 対応 |
|------|------|
| レスポンシブ | 上記ブレークポイントで padding・font-size を調整。モバイルでは縦積みレイアウト |
| アクセシビリティ | セマンティックHTML（`<section>`, `<article>`）、aria-labelledby、リンク aria-label、focus-visible、キーボード操作 |
| パフォーマンス | アニメーションは控えめに、不要な画像は使用しない |
| SEO | H1 にページタイトル、section＋h2 で構造化 |

## 8. コンテンツ（サンプル）

### 8.1 ページタイトル
- **H1**: 「このサイトについて」
- **リード**: 「このポートフォリオサイトの技術選定と開発手法について紹介します。」

### 8.2 サイトの目的
- **H2**: 「ポートフォリオサイトとしての役割」
- **本文**: 「自分に興味を持っていただいた皆様に対して、アピールする場としての役割と、自分自身の過去を見直す役割を期待して作成しています。」

- **H2**: 「技術的な興味を満たす場としての役割」
- **本文**: 「ポートフォリオの改修や、遊び場の追加を通して、自身の技術的なインプットとアウトプットとしても役割を期待しています。また、極力ライブラリを使わずに実装することを目指しています。」

### 8.3 技術スタック
- **フロントエンド**: Next.js 15, React 19, TypeScript, CSS Modules + SCSS, Atomic Design
- **バックエンド**: Next.js 15, TypeScript（将来: Go）
- **DB**: Google Spreadsheet（将来: DB）
- **インフラ**: Vercel
- **その他**: Biome（Lint/Format）、Zustand（状態管理）、Radix UI / Headless UI（UIコンポーネント）、React Icons（アイコン）、safe-chain / Shannon（セキュリティ）

### 8.4 AI開発について
- **概要**: 「このサイトはAI開発ツール（Cursor）を活用して開発しています。AI開発により、要件の整理から設計、デザイン、実装、レビュー、PR作成まで、一貫したワークフローで高品質な開発を実現しています。」
- **ワークフロー**: 6ステップ（要件の具体化、詳細設計、デザイン、開発、レビュー・セキュリティチェック、PR作成）
