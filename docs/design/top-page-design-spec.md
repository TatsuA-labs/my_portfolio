# トップページ デザイン仕様書（最終稿）

現状の実装に引きずられず、「最適なポートフォリオ」を目的から定義し直したデザインです。承認後に実装に進みます。

---

## 1. デザインの目的と原則

### 1.1 目的
- **誰向けか**: 採用担当・クライアント・協業したい開発者
- **何を伝えるか**: 誰か・何ができるか・実績の証拠・どう連絡するか
- **ゴール**: 5〜10秒で「この人に会いたい」と思わせ、スクロールで根拠を示し、最後に接触を促す

### 1.2 原則（0ベースで採用）
| 原則 | 具体的な方針 |
|------|----------------|
| **情報の優先順位** | ヒーローで一言で価値提示 → スキル・実績・受賞で証拠 → CTAで行動を一つに集約 |
| **可読性** | 行の長さを抑える（本文ブロック max-width 約 65ch）、行間 1.6〜1.75、段落間に余白 |
| **余白** | スペーシングをスケールで統一し、詰めすぎない。セクション間に「息をつく」余白 |
| **色は絞る** | 背景・文字・補足＋**1つのアクセント**（CTA・リンク）。ダークモードは既存変数を拡張 |
| **一貫性** | 見出し・本文・キャプションのフォントサイズと太さをスケールで統一 |
| **レスポンシブ** | モバイルファースト。タッチしやすいタップ領域、読みやすいフォントサイズ |
| **アクセシビリティ** | コントラスト比 WCAG AA、フォーカス表示、セマンティックHTML・ARIA |

## 2. デザインシステム（新規定義）

### 2.1 カラー
| 役割 | ライト | ダーク | 用途 |
|------|--------|--------|------|
| 背景 | #ffffff | #0a0a0a | ページ背景（既存変数） |
| 文字 | #171717 | #ededed | 本文・見出し（既存変数） |
| 補足 | #6b7280 | #9ca3af | 日付・キャリア・サブテキスト |
| アクセント | #2563eb | #60a5fa | CTAボタン・主要リンク（新規変数推奨） |
| セクション背景（任意） | #f8fafc | #111827 | セクション交互の差し色（任意） |

- 既存の `--background` / `--foreground` は維持し、`--muted` と `--accent` を追加する形を推奨。

### 2.2 タイポグラフィスケール
| 役割 | サイズ | 行間 | 太さ | 用途 |
|------|--------|------|------|------|
| H1 | 1.75rem〜2rem（28〜32px） | 1.25 | 700 | ヒーロー見出し 1行 |
| H2 | 1.5rem（24px） | 1.3 | 700 | セクション見出し |
| リード | 1.125rem（18px） | 1.6 | 400 | ヒーロー直下の短い説明 |
| 本文 | 1rem（16px） | 1.7 | 400 | 通常段落 |
| キャプション・補足 | 0.875rem（14px） | 1.5 | 400 | 日付・キャリア・ラベル |

- フォント: 既存の Arial, Helvetica, sans-serif のままでも可。より「ポートフォリオらしい」印象にする場合は **Inter** や **Lato** など1フォント追加を検討（読みやすさ優先）。

### 2.3 スペーシングスケール（8pxベース）
| トークン | 値 | 用途例 |
|----------|-----|--------|
| xs | 8px | アイコンとラベルの間 |
| sm | 16px | リスト項目間、カード内パディング |
| md | 24px | セクション内ブロック間 |
| lg | 32px | 見出しとコンテンツの間 |
| xl | 48px | セクション内のまとまり間 |
| 2xl | 64px | セクション間（デスクトップ） |
| 3xl | 96px | ヒーロー上下（デスクトップ） |

- モバイル: セクション間 48px、ヒーロー 64px 程度に縮小可。

### 2.4 ブレークポイント
| 名前 | 幅 | 方針 |
|------|-----|------|
| モバイル | 〜767px | 1カラム、タップ領域 44px 以上 |
| タブレット | 768px〜1023px | 1〜2カラム、余白は中程度 |
| デスクトップ | 1024px〜 | max-width でコンテンツ幅を制限、余白を大きく |

## 3. ページ構造とセクション順（0ベース）

1. **ヘッダー** — 他ページへの動線（ナビゲーション）
2. **ヒーロー** — 誰か・何ができるか（一言）・写真・短い説明・SNS
3. **スキル** — 技術スタックの証拠
4. **開発実績** — 何をしたか・役割・成果
5. **受賞歴** — 信頼の証
6. **CTA** — お問い合わせへの導線を1つに集約
7. **フッター** — 他ページへの動線の繰り返し（任意だが推奨）

---

## 3.1 ナビゲーション・他ページへの動線

**結論**: **ヘッダーとフッターの両方**をトップページのデザインに含めることを推奨する。

| 観点 | ヘッダー | フッター |
|------|----------|----------|
| **必須か** | **推奨（事実上必須に近い）** | **推奨（あった方がよい）** |
| **理由** | 初回表示から「キャリア」「サイトについて」などへすぐ遷移できる。sticky にすればスクロール後も常に動線を確保できる。 | ページ末尾でナビを繰り返すと、長いスクロール後の離脱を防ぎ、キーボード・スクリーンリーダー利用者も最後にタブでナビに到達しやすい。 |
| **動線が必須か** | 他ページへのリンクは**必須**。実装は「ヘッダー＋フッター」で両方提供する。 | 同上。 |

- ヘッダーだけでも動線は満たせるが、フッターを足すことで UX とアクセシビリティが向上するため、**両方**を対象に含める。
- リンク先: **ホーム（/）・キャリア（/career）・遊び場（/play_ground）・サイトについて（/about_site）**。お問い合わせはトップの CTA から /contact へ誘導するため、ナビには含めても含めなくてもよい（含める場合は「お問い合わせ」を追加可）。

## 4. コンポーネント仕様（0ベース）

### 4.0 ヘッダー（Organism）

トップページデザインに含む。デザインシステムで新規に設計する（既存ヘッダーは置き換え）。

| 要素 | 仕様 | 意図 |
|------|------|------|
| 配置 | ページ最上部。sticky（position: sticky; top: 0）でスクロール時も表示 | 常に他ページへ遷移可能に |
| コンテナ | 全幅。背景は `--background` またはやや濃い/薄い程度。影は軽く（0 2px 4px rgba(0,0,0,0.06) 等） | ヒーローを邪魔しない |
| ナビ | 横並び。リンク: ホーム・キャリア・遊び場・サイトについて。同一行に収まる幅で、モバイルでは wrap またはハンバーガー検討 | 動線を明確に |
| 見た目 | テキストは本文サイズ（1rem）またはキャプション（0.875rem）。通常時は `--foreground`、hover 時は `--accent`。アイコンは Heroicons で統一（既存と同様） | トークンで統一 |
| タップ領域 | 各リンクは最小 44px 高さを確保 | アクセシビリティ |
| アクセシビリティ | `<header>` 内に `<nav aria-label="メインナビゲーション">`。各リンクに適切な aria-label またはテキスト | |

- ロゴやサイト名は任意。入れる場合はナビの左端に小さく。

### 4.0.1 フッター（Organism）

トップページデザインに含む。新規コンポーネント。

| 要素 | 仕様 | 意図 |
|------|------|------|
| 配置 | ページ最下部（CTA セクションの下） | スクロール終端でナビを繰り返す |
| コンテナ | 全幅。背景は `--section-bg` または `--background`。padding 2xl 上下、sm 左右 | セクションとトーンを合わせる |
| 内容 | ナビリンク（ヘッダーと同一: ホーム・キャリア・遊び場・サイトについて）。中央寄せまたは横並び。2行目に © 2025 名前 など任意 | ミニマルに |
| 見た目 | テキストはキャプションサイズ（0.875rem）、色は `--muted`。hover で `--accent` | 主張しすぎない |
| アクセシビリティ | `<footer>` 内に `<nav aria-label="フッターナビゲーション">`。リンクは同じ aria-label でよい | |

- ヘッダーとフッターのリンク先は同一でよい。お問い合わせリンクを足す場合は「お問い合わせ」を追加。

### 4.1 ヒーロー（Organism）

**レイアウト**: **中央寄せ・縦積み**にする。

| 要素 | 仕様 | 意図 |
|------|------|------|
| コンテナ | 全幅、padding 上下 2xl〜3xl、中央寄せ | 余白で「入り口」を明確に |
| 画像 | 上に配置。幅 240px〜280px、アスペクト比 1:1（円）または 4:3（角丸）。object-fit: cover | 人物としての信頼感、モバイルでも崩れない |
| H1 | 画像の下、1行。H1のフォントサイズ・行間 | 最初に目に入るメッセージ |
| リード文 | H1の下、1〜2行。リードのフォントサイズ・行間 | 補足説明は短く |
| 自己紹介 | 2〜3段落、本文サイズ。max-width 約 65ch で中央寄せ | 可読性 |
| SNS | 段落の下。GitHub・LinkedIn、アイコン 24px、gap 12px。hover でアクセント色 or 下線 | 発見しやすく、邪魔にならない |
| キャリア | 「Webエンジニア Since 2021」など、キャプションサイズ・色（muted） | 経歴の一言 |

- ボーダーでの区切りは使わず、余白とタイポグラフィで階層を表現する。

### 4.2 SNSリンク（Molecule）

| 要素 | 仕様 |
|------|------|
| 配置 | ヒーロー内のみ。横並び、gap 12px |
| 見た目 | アイコンのみ、またはアイコン＋「GitHub」「LinkedIn」テキスト。Heroicons 使用 |
| インタラクション | hover で color: accent または opacity 変化。focus-visible でアウトライン |
| アクセシビリティ | aria-label（「GitHub へ」等）、外部リンクは rel="noopener noreferrer" |

### 4.3 スキル（Organism）

| 要素 | 仕様 |
|------|------|
| セクション | padding 上下 2xl、コンテナ max-width 1100px 程度 |
| 見出し | H2＋任意で短い説明文。下に md 以上の余白 |
| リスト | フレームワーク・言語など、既存データを活かす。見た目は「ラベル＋経験」を読みやすく。カードにする場合は角丸・軽いシャドウ or 枠線で統一 |
| 装飾 | セクション間の区切りは「余白」または「薄い背景色の差」で。太い線・複数色は避ける |

### 4.4 開発実績（Organism）

| 要素 | 仕様 |
|------|------|
| セクション | スキルと同様の padding・max-width |
| 見出し | H2＋余白 |
| カード | 1カード＝1実績。タイトル（H3）・役割・説明。画像がある場合はアスペクト比固定・角丸。hover は軽く（シャドウ or 枠） |
| メイン/サブ | 既存の Main/Sub の区別は、サイズ・余白で表現（ボーダー多用は避ける） |

### 4.5 受賞歴（Organism）

| 要素 | 仕様 |
|------|------|
| セクション | 同上 |
| 見出し | H2 |
| ブロック | 日付・賞名・説明・コメントを階層立てて表示。1ブロックにまとめ、角丸＋軽い背景 or 枠で他セクションとトーンを合わせる |
| 画像 | ある場合、比率を決めて配置（既存の award 画像を活かす） |

### 4.6 CTA（Organism）

| 要素 | 仕様 |
|------|------|
| セクション | 全幅 or コンテナ中央。padding 2xl。背景をアクセントの薄い版 or セクション差し色にしても可 |
| 見出し | 「お問い合わせ」H2 |
| 説明 | 1〜2文。本文 or リード |
| ボタン | 1つ。ラベル「お問い合わせはこちら」等。背景＝アクセント、文字＝白（または反転）。hover で濃淡 |
| 配置 | テキスト・ボタンともに中央寄せ |

## 5. 情報の見やすさ・UX

| 観点 | 対応 |
|------|------|
| 階層 | H1 は1回（ヒーロー）、各セクション H2、カード内 H3。番号飛ばしなし |
| コントラスト | 本文・背景は AA 以上。補足は muted で十分な比 |
| 行長 | 本文ブロック max-width: 65ch または 720px |
| CTA | ページ内で「やること」を1つに。ボタンはアクセント色で目立たせる |
| ナビ | ヘッダー＋フッターで他ページへの動線を確保（本デザインに含む）。必要ならスムーススクロールや目次は後から検討 |

## 6. レスポンシブ・アクセシビリティ・SEO

| 項目 | 対応 |
|------|------|
| レスポンシブ | 上記ブレークポイントで padding・font-size・画像サイズを調整。ヒーローは常に縦積み |
| アクセシビリティ | セマンティックHTML、aria-labelledby、リンク aria-label、画像 alt、focus-visible、キーボード操作 |
| パフォーマンス | 画像は Next/Image、priority はヒーローのみ。アニメーションは控えめに |
| SEO | H1 にキャッチコピー、section＋h2 で構造化 |
