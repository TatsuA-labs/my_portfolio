# キャリアページ デザイン仕様書（ゼロベース）

現状の実装に引きずられず、「最適なキャリアページ」を目的から定義し直したデザインです。トップページのv2デザインシステムと統一感を保ちながら、キャリア情報に最適なレイアウトを提案します。

---

## 1. デザインの目的と原則

### 1.1 目的
- **誰向けか**: 採用担当・クライアント・協業したい開発者
- **何を伝えるか**: 職歴・学歴の時系列、各期間での役割・担当業務・担当案件、追加情報
- **ゴール**: 時系列が一目で分かり、各職歴・学歴の詳細が読みやすく、信頼感を与える

### 1.2 原則（ゼロベースで採用）
| 原則 | 具体的な方針 |
|------|----------------|
| **時系列の明確化** | 期間を視覚的に強調し、最新が上（降順）で時系列を分かりやすく |
| **情報の階層化** | 期間 → 会社名/学校名 → 役割 → 担当業務 → 担当案件 → 追加情報の順で階層を明確に |
| **可読性** | カード形式で情報を整理し、適切な余白と行間で読みやすく |
| **統一感** | トップページのv2デザインシステム（色・余白・タイポグラフィ）を活用 |
| **視覚的な整理** | 担当案件はタグ/バッジ形式で視覚的に分かりやすく、追加情報はアイコン付きリンクで整理 |
| **レスポンシブ** | モバイルファースト。カードは全幅、タグは折り返し、リンクは縦積み |
| **アクセシビリティ** | コントラスト比 WCAG AA、適切な見出し構造、セマンティックHTML・ARIA |

## 2. デザインシステム（トップページv2と統一）

### 2.1 カラー（既存トークンを活用）
| 役割 | ライト | ダーク | 用途 |
|------|--------|--------|------|
| 背景 | #ffffff | #0a0a0a | カードの背景（`--background`） |
| 文字 | #171717 | #ededed | 本文・見出し（`--foreground`） |
| 補足 | #6b7280 | #9ca3af | 期間・補足情報（`--muted`） |
| アクセント | #2563eb | #60a5fa | リンク・タグ（`--accent`） |
| セクション背景 | #f8fafc | #111827 | セクション交互の差し色（`--section-bg`） |

### 2.2 タイポグラフィスケール（トップページと統一）
| 役割 | サイズ | 行間 | 太さ | 用途 |
|------|--------|------|------|------|
| H1 | 1.75rem〜2rem（28〜32px） | 1.25 | 700 | ページタイトル「キャリア」 |
| H2 | 1.5rem（24px） | 1.3 | 700 | セクション見出し「職歴」「学歴」 |
| H3 | 1.25rem（20px） | 1.4 | 600 | 会社名・学校名 |
| 本文 | 1rem（16px） | 1.7 | 400 | 担当業務・説明文 |
| 期間・補足 | 0.875rem（14px） | 1.5 | 400 | 期間・ラベル |
| タグ | 0.875rem（14px） | 1.4 | 500 | 担当案件タグ |

### 2.3 スペーシングスケール（8pxベース、トップページと統一）
| トークン | 値 | 用途例 |
|----------|-----|--------|
| xs | 8px | タグ間のgap、アイコンとラベルの間 |
| sm | 16px | カード内パディング、リスト項目間 |
| md | 24px | カード内ブロック間 |
| lg | 32px | 見出しとコンテンツの間 |
| xl | 48px | カード間のgap（モバイル） |
| 2xl | 64px | セクション間、カード間のgap（デスクトップ） |

### 2.4 ブレークポイント（トップページと統一）
| 名前 | 幅 | 方針 |
|------|-----|------|
| モバイル | 〜767px | 1カラム、カード全幅、タグ折り返し |
| タブレット | 768px〜1023px | 1カラム、max-width制限 |
| デスクトップ | 1024px〜 | max-width 1100px、中央寄せ |

## 3. ページ構造とセクション順

1. **ヘッダー** — 他ページへの動線（既存のHeaderコンポーネントを活用）
2. **ページタイトル** — H1「キャリア」
3. **職歴セクション** — H2「職歴」+ CareerCard[]（降順）
4. **学歴セクション** — H2「学歴」+ SchoolCard[]（降順）
5. **フッター** — 他ページへの動線（既存のFooterコンポーネントを活用）

| 要素 | 仕様 | 意図 |

| 追加情報セクション | `.school_section`クラスでラップ、margin-bottom md（最後のセクションは0）、職歴カードのセクション構造と統一 | カードのサイズを統一し、視覚的なバランスを取る |
| 追加情報 | ExternalLinks（アイコン付きリンク）、横並び（デスクトップ）または縦積み（モバイル）、gap sm | 追加情報を整理 |

```
│ 期間                │
│ 学校名              │
│                     │

│ [🔗 リンク1]        │
│ [🔗 リンク2]        │
└─────────────────────┘
```

**カードサイズの統一**:
- 職歴カードと学歴カードの両方に同じpadding（`var(--sm)` = 16px）を適用
- 学歴カードの学校名の下に`margin-bottom: var(--md)`を追加（職歴カードの役割の下の余白と同じ）
- 追加情報を`.school_section`クラスでラップし、`margin-bottom: var(--md)`を適用（最後のセクションは0）
- **幅の統一**: `width: 100%`と`max-width: 1100px`を設定し、中身に関係なく同じ幅になるようにする
- **高さの統一**: 職歴カードは`min-height: 300px`（デスクトップ）または`250px`（モバイル）、学歴カードは`min-height: 150px`（デスクトップ）または`125px`（モバイル）を設定し、中身が少ないカードも同じ最小高さになるようにする。中身が多い場合は自動的に伸びる
- **Flexboxレイアウト**: `display: flex`と`flex-direction: column`を設定し、カード内の要素を縦に配置
- これにより、職歴カードと学歴カードの視覚的なバランスが統一され、中身に関係なく同じサイズになる

## 5. 情報の見やすさ・UX

| 観点 | 対応 |
|------|------|
| 階層 | H1（ページタイトル）→ H2（セクション）→ H3（会社名・学校名）の見出し構造を明確に |
| 時系列 | 期間を`--muted`色で視覚的に強調し、降順（最新が上）で時系列を分かりやすく |
| コントラスト | 本文・背景は AA 以上。期間・補足情報は`--muted`で十分な比 |
| カード形式 | 各職歴・学歴をカードで区切り、情報を整理 |
| タグ形式 | 担当案件をタグ/バッジ形式で視覚的に分かりやすく |
| アイコン付きリンク | 追加情報をアイコン付きリンクで整理し、外部リンクを明確に |

## 6. レスポンシブ・アクセシビリティ・SEO

| 項目 | 対応 |
|------|------|
| レスポンシブ | ブレークポイントでpadding・font-size・gapを調整。カードは全幅（モバイル）、max-width制限（デスクトップ）。タグは折り返し、リンクは縦積み（モバイル） |
| アクセシビリティ | セマンティックHTML（`<section>`, `<article>`）、適切な見出し構造（h1-h3）、aria-labelledby、リンクaria-label、外部リンクは`rel="noopener noreferrer"`、キーボード操作対応 |
| パフォーマンス | 画像は使用しない（必要に応じて将来追加可能）。アニメーションは控えめ（hover効果のみ） |
| SEO | H1に「キャリア」、section＋h2で構造化、適切なメタタグ |
